# 使用医院认可的文字方位指引，不建设路径计算

Status: Accepted

Accepted: 2026-09-01

MediPet 的个人开发版采用 `FakeHospitalOperations` 加载的版本化受控数据集，按命名起点、院内服务地点和普通或无障碍模式精确返回“明和虚构医院”的有序文字指引。这里的“权威”只表示应用照原文使用受控数据，而不表示真实医院信息。文字可以提及入口、楼层、电梯和地标，但系统不把它们解析为建筑、楼层、节点或连通边，也不进行路线拼接、反转、地图搜索、实时定位或模型补全。未来若改接其他数据源，应复用同一 `HospitalOperations` 契约；只有出现结构化地图、通行状态和明确维护契约时，才以新的 ADR 重新评估路径计算。
