# 使用模型风险初筛并由医院人员最终审核

MediPet 将强制的结构化模型风险初筛放在普通 Agent 流程之前；`urgent`、`emergency`、`uncertain`、模型失败或格式失败均暂停普通流程并进入人工风险审核，等待期间向就诊参与者显示保守提示。模型提供辅助判断，医院人员拥有最终处理决定；SafetyPolicy 是高于普通 Skill 的受保护、不可删除、可版本化资源，医院可修改判断指引但不能修改强制执行、暂停和失败保守处理等平台约束。该决策取代 `docs/design/architecture.md` 中“由确定性医院规则独立裁决是否停止普通协助”的原始假设，同时保留模型不能执行最终医疗裁决的边界。
