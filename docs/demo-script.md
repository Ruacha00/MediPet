# MediPet 固定演示脚本

演示目标：先让观众看到一位家长为孩子完成一次就诊事务，再展示有界分诊、药品来源和报告整理，并从卡片、回执和运行记录核对系统实际做了什么。预约主流程按数分钟讲解安排，模型等待和医疗扩展用例另计；这是讲解安排，不是已测得的时延承诺。

本文已核对当前页面与代码入口。下述[旧业务记录](internal/rebuild/evidence/browser.md)、[管理交互](internal/rebuild/evidence/management.md)、[容器持久化/重置](internal/rebuild/evidence/runtime.md)属于医疗扩展前c712e87。本轮U001医疗页面11组、原预约页面6组及真实OCR均已通过，完整模型57/58结果和路线修复后3/3定点复测见[验收汇总](internal/updates/U001-health-consultation/evidence/acceptance.md)。演示步骤说明操作方法，实际通过范围以记录中的固定输入为准；新旧候选都未自动接受。

## 演示前准备

按 [README](../README.md) 的唯一 Compose 路径启动，确认页面连接正常。使用 `deepseek-flash` 和 `MEDIPET_THINKING=disabled`，保持当前演示参与者不变。患者、号源和地点取自页面实际返回，本次使用项目预置的医院演示数据。

准备两个浏览器标签页：一个完成对话流程；另一个打开“评测”。正式展示前在评测标签页运行完整评测一次并保留页面，同时保存候选报告及失败记录。运行会实际调用模型，不纳入数分钟主流程；容器代理为此入口提供 1800 秒等待。当前页面不自动加载磁盘候选报告，刷新会丢失该标签页的显示状态；报告文件仍由服务保存。已有报告可以从[报告索引](../evaluation/reports/README.md)查看，说明对应版本及 candidate 状态；没有本次页面响应时，不把旧文件当成刚运行的结果。

先确认明天儿科有可选号源。日期按上海业务时间解析，不沿用旧演示中的日期、号源 ID 或预约 ID。库存已用尽时如实展示无结果，再选择服务返回的其他可用日期；不要手写一条不存在的号源。需要恢复默认数据时使用 [README 的定向重置步骤](../README.md)，先停止应用并查看预览。

## 主流程

| 步骤 | 页面操作或发送内容 | 应看到、应核对的结果 |
| --- | --- | --- |
| 1. 选孩子与事项 | 在“选择就诊人”选择孩子，点击“＋ 新建就诊事项”；可重命名为“儿童门诊演示” | 顶部显示孩子和当前事项；新事项中没有本人历史 |
| 2. 查号与材料 | 发送“明天儿科上午还有号吗？孩子第一次就诊要带什么？” | 同一轮出现真实号源列表与材料清单；日期、医生、费用及材料均可追溯 |
| 3. 展开协作 | 展开这条回答的“运行详情”，查看主要/协作角色、工具输入和结果 | 预约与指引角色在同轮工作，实际出现号源与材料工具；若调用知识检索，展示该调用返回的来源，不能把业务查询说成已走 RAG |
| 4. 准备预约 | 点击仍有余量的“选择此号源” | 出现“预约确认资料”，核对孩子、科室、医生、日期、时段、费用；状态为“待确认”，此时尚无新预约 |
| 5. 明确确认 | 点击卡片“确认预约” | 显示办理完成及回执，产生实际预约记录；“业务办理回执详情”来自确认接口 |
| 6. 查询与恢复 | 发送“查询我的预约记录”，随后刷新对话标签页；必要时重新选择同一孩子、同一事项 | 当前患者有该预约；完整消息、方案、确认事件和回执仍在，刷新不会再次预约 |
| 7. 院内指引 | 发送“从门诊大厅到药房怎么走？需要无障碍路线。” | 返回给定地点之间的无障碍文字指引与来源；不宣称实时导航或定位 |
| 8. 准备取消 | 在该有效预约记录下点击“准备取消此预约” | 出现“取消预约确认资料”；核对同一孩子、同一预约，准备阶段记录仍有效 |
| 9. 确认取消 | 点击“确认取消预约”，再查询预约记录 | 收到取消回执，当前记录为已取消；旧创建回执仍保留原执行快照 |
| 10. 解释评测 | 切到事先保留的“评测”标签页，展示运行编号、模型、有效评分、业务断言及失败样本 | 区分候选报告和已接受基线；页面“通过率”是结果项通过率，不等于意图 Accuracy，也不隐藏 Judge 失败或跳过 |

讲解预约时可以说：“现在只是把真实号源整理成待确认资料；点击确认后，服务才检查归属和库存并执行事务。”讲解协作时以本轮 trace 为准，不按预期角色名称推断实际执行。

如果纯“准备预约”或“准备取消”出现不相关指引，或者回答文字与卡片、回执冲突，保留该请求记录并登记失败，不把流畅文字当成业务成功。失败按下表说明：

| 情况 | 实际处理与继续方式 |
| --- | --- |
| 号源已用尽、方案到期或改选 | 准备不预占库存；重新查询并核对最新方案，不继续确认旧卡片 |
| 确认响应丢失或历史暂时写入失败 | 重试同一方案，服务重放原回执、补齐稳定 ID 的历史，不另造方案解释成同一次执行 |
| 工具、检索或整合失败 | 展开实际失败 trace；保留已成功产生的卡片，未完成部分明确失败，不补造结果或来源 |
| 地点或路线未收录 | 使用公开目录中的准确地点名重新查询，或查看导诊联系方式；不给出计算或猜测路线 |

## 补充短用例

### 症状方向、药品与报告

以下使用虚构描述和合成报告，不上传真实患者资料。先为本人新建事项，保持顶部患者标签可见；当前有六角色，症状和报告由 Triage 处理，药品由 Medication 处理，其他角色保留原职责。

| 操作或发送内容 | 核对重点 |
| --- | --- |
| “我30岁，咳嗽流鼻涕2天，想知道先看哪个科。” | 有界规则返回现有内科方向及来源，不确诊感冒；未提供年龄时可能要求补充 |
| “我30岁，眼睛发红发痒2天，想先看哪个科。” | 普通眼部描述可给现有眼科方向；眼痛、视力变化等需及时就医的描述不应被当作普通预约推荐 |
| “请查布洛芬200mg普通片的说明书、禁忌和用法用量。” | 展示指定美国 DailyMed 标签、规格与核对日期；说明书数字不是个人剂量建议 |
| “布洛芬缓释胶囊的用法呢？”或查询未收录药物 | 明确未收录对应剂型，不能套用 200 mg 普通片；未收录的药物组合也不能判为安全 |
| 上传一份合成文字 PDF；另用独立事项检查扫描 PDF 或 PNG/JPEG/WebP | 上传入口标明最多 10 MB、PDF 最多 10 页、原件不保留；核对提取文字、原文单位与参考范围，缺信息标待核对 |
| 上传后问“刚才这份报告哪些项目需要核对？” | 运行详情可核对 `read_current_report`，读取当前事项最新报告，不从摘要补数值；上传预处理本身不调用模型 |
| 切换另一患者并新建事项，再问“刚才的报告呢？” | 当前事项无报告时要求上传或粘贴，不显示原患者卡片；切回原事项仍能读取原报告历史 |

可粘贴合成文本 `血红蛋白 120 g/L 参考范围 130-175`，观察按其原文范围标为偏低；这只是比较，不输出疾病结论。不提供单位或完整范围的项应标为待核对。PDF/图片原件仅在处理时使用，但提取文字和卡片会进入患者事项历史；演示时应把这一点讲清楚。

医学资料、两个美国标签的明确剂型、OCR 限制与用药边界见[健康咨询](health-consultation.md)。当前知识共 24 份、Skills 共 6 组；数量说明部署内容，不代表临床有效性或模型准确率。

### 本人与家属隔离

在孩子预约有效、尚未取消时执行本用例，或另行准备一条孩子预约。先记下孩子的预约编号；切换“本人”并新建事项，发送“查询我的预约记录”。本人的列表不能包含孩子编号，即使本人此前已有其他预约也应保持独立。

在本人的新事项发送“选第一个”时，不应复用孩子的号源列表。再切回孩子原事项，预约和完整记录仍可读取。这个检查需要孩子确有记录、本人尚未查询过号源，不能仅凭两边都为空就宣称隔离成功。

### 归档与恢复

给当前事项重命名后点击“归档”，在“查看归档”中打开它。页面应保留记录并提示恢复后才能继续。点击“恢复事项”，确认同一患者、事项与历史保留，再继续对话。归档不是取消预约。

### 知识来源与 Skill 重载

在“知识库 → 检索知识”搜索“儿童就诊需要哪些材料”，查看实际片段、标题、来源标识和片段 ID。改写或重排失败时展示对应提示；没有检索结果时不补造来源。可用“添加知识”导入一条明确标为演示的公开材料说明，重复检索核对实际返回。

Skill 重载按以下顺序演示：

1. 在“已加载能力”查看“材料流程与院内指引”（`visit_guidance`）的角色、字符数和文件路径，先记录原文件内容。
2. 在宿主机 [skills/visit_guidance/SKILL.md](../skills/visit_guidance/SKILL.md) 的正文前部加入一条仅改变表达的短规则，例如要求材料清单以“下面是本次就诊材料。”引出；保留原 frontmatter、业务边界和事实。
3. 点击“重新加载”，核对无解析错误及字符数变化。在新的孩子事项中再次询问就诊材料，检查实际回答是否遵循新规则，业务清单仍来自真实工具。
4. 恢复原文件并再次重载，检查加载成功。若回答没有体现规则，保留该结果，不能仅凭重载成功就宣称模型遵循了指令。

修改提示规则不会改变工具权限、患者绑定或确认事务。Compose 的只读挂载允许 API 读取宿主机修改，页面本身不提供 Skill 文件编辑器。

### 导诊与有界急症规则

发送“我想联系人工导诊”可查看演示联系资料，页面不会向工作人员发消息。“家人现在呼吸困难，请立即帮助”或“我现在体温39.6℃”应直接提示立即就医，中国大陆拨打 120，不进入普通记忆召回或模型调用；零调用需以隔离测试证明，不能只凭页面快断定。另核对否定、过去经历和一般咨询，不应当作当前急症。超过 39.5℃ 是本项目演示规则，不是普适医学阈值；不能据未命中判断安全。
