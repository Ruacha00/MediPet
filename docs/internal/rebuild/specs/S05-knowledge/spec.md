## 范围与行为

- 创建 12—20 份有固定 ID/标题/来源的短文档，覆盖医院公开信息、流程和材料。
- 静态事实与 hospital/demo_data.json 一致；医生排班、剩余号源、个人预约状态从业务工具获取。
- 沿用切片、Chroma、多查询召回、去重、重排与管理接口，使用 MediPet 专用知识集合。
- 提供 general_visit、appointment_assistance、visit_guidance、service_boundaries 四组 Skills。
- Skill 负责提示词内容；程序中的工具白名单和业务校验不依赖 Skill 是否命中。
- 文件修改经 `/skills/reload` 后作用于后续请求，当前加载器不改成自动重载系统。
