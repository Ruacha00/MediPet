# A05 · 共享急症检查和导诊固定响应

## 目标

提供单一可复用的急症演示检测，并使直接编排在普通召回/模型请求前返回固定响应。
人工导诊明确展示联系方式与可复制摘要，不声称已把消息交给真实工作人员。

## 实施范围

- 在现有意图模块提供共享检测入口，固定匹配演示语句及必要的否定/一般咨询排除规则。
- 编排入口首先执行该检测；命中后由 EscalationAgent 固定响应，不走普通角色或预约工具。
- 输出既定急症提示与 H02 的统一导诊联系资料，可附 contact_info artifact。
- 普通“联系人工导诊”返回联系信息；若保留摘要助手，只生成可复制摘要。
- 向 I02 提供同一检测函数和命中结果，API 前置调用留给 I02，避免双写 api/main.py。
- 规则只覆盖固定演示范围，不进行疾病诊断、推荐科室或建设症状推理系统。

## 输入与输出

输入：当前消息与已固定的演示规则；身份沿用 Request，不由急症文本重绑定患者。
输出：命中标记、固定响应及来源明确的联系信息；未命中返回普通流程可继续的结果。
记录实际跳过的步骤，不编造模型或工具成功 trace。

## 验收

- [x] 固定急症正例在模型客户端完全不可用时返回既定响应。
- [x] 用抛错/计数替身证明命中时未执行普通记忆召回、意图模型、主辅任务或预约工具。
- [x] “没有出现该急症信号”等否定表达及“这种信号是什么意思”等一般咨询反例不误触发。
- [x] 普通导诊联系含演示资料和可复制内容，不出现“已提交/正在接入真人”等虚假状态。
- [x] 急症中断不生成预约、不执行当前待确认方案、不更改当前患者。
- [x] 提供共享函数给 I02；API 与直接编排行为一致的接口级验收明确留给 I02。
