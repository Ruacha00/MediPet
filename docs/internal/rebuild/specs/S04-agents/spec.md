- 将业务意图、实体、四类角色、领域打分、主辅协作和工具声明适配为医院场景。
- 保留三路识别、投票与降级、实例评分、最多三次模型请求的工具循环、`asyncio.gather` 和 `ResponseComposer`。
- 模型工具只能查询或准备方案；最终预约/取消由确认接口调用业务服务。
- 身份来自已校验的事项上下文；本轮 artifacts 与 trace 从工具逐层返回，不存入共享 Agent 实例。
- 急症固定演示规则在记忆召回与模型调用前生效；直接编排和 API 使用同一检测函数。
- 角色前端标签由前端 spec 负责；事项验证、API 响应与确认入口由接口 spec 负责；不在本 spec 新建框架。
