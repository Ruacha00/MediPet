# H03 实现医院目录准备清单和文字指引查询

## 目标

交付不依赖模型的只读医院查询服务，供 General 与 Guidance 工具接入。

## 实施范围

- 实现医院、科室、医生及地点目录查询，并支持计划工具要求的筛选。
- 根据科室及就诊类型返回预置准备清单与来源。
- 按起点、目的地、普通/无障碍模式查找有序文字指引及来源。
- 返回 H01 定义的服务结果与 `catalog`、`visit_checklist`、`wayfinding` 数据。
- 对缺字段、未知对象或未收录路线返回稳定失败类别；保留澄清所需信息。
- 日期相关筛选采用可注入时钟；精确指引直接查询数据，不进行路线计算。

## 输入与输出

输入：H02 静态数据、H01 模型和查询参数。输出：可直接调用的查询方法及确定性测试；工具声明、RAG 和 API 接入在下游实现。

## 验收

- [x] 医院、科室、医生筛选仅返回演示数据中的实体，排序和标识稳定。
- [x] 准备清单及两类指引的文字、顺序与来源和数据文件一致。
- [x] 未知地点、未覆盖路线、缺失筛选条件有明确结果，不产生虚构数据。
- [x] 固定时钟测试覆盖成功、空结果和失败路径；查询不创建方案或预约。

## 依赖与并行

依赖 H02 的完整内容与 H01 契约。可与 M01/M02 的 `memory/visit_store.py` 工作并行；与 H04 共享 `hospital/service.py` 和测试文件，按 H03→H04 顺序合入。
