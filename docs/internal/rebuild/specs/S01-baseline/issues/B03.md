# B03 接通开发与容器运行配置

## 目标

让后端、前端、Redis、Chroma 通过一套明确配置启动。

## 实施范围

- 安装固定版本应用与测试依赖，优先 Python 3.12；依赖变更只针对实际安装或运行错误并记录理由。
- 统一服务名、数据卷、MediPet 参数与模型 SDK 参数；Redis 启用 AOF，Chroma 使用专用数据空间。
- 开发使用 API 8000、Vite 5173；容器前端计划 8088，Nginx 保持 `/api/python` 代理一致；区分宿主机与容器连接地址。
- Prometheus 可选；外部告警保持默认未配置。更新 README 的当前基准启动步骤。

## 输入与输出

输入：B01/B02 的目录、依赖、请求入口。输出：可启动配置、环境示例与测试依赖；示例只含占位值。
