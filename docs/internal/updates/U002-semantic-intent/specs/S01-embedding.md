# S01 中文模型与编码器

归属：[U002 计划](../plan.md)。任务：01、02。状态见 issue，不由本文推断已实现。

## 交付

固定 `BAAI/bge-small-zh-v1.5` 的完整版本和可校验资产；在隔离构建环境导出 FP32 ONNX，生产运行复用兼容的 ONNX Runtime、NumPy、tokenizers。新增窄批量接口，支持语义后端、原 256 维字符哈希后端和可注入测试替身，保持聊天模型客户端独立。

## 验收

- 完整记录来源、MIT 许可、模型与 tokenizer 指纹、导出工具/运行依赖版本；无浮动 `main` 下载和运行时模型导出。
- 512 维、CLS pooling、L2 归一化、512 token 上限、双方无检索前缀与参考实现一致。
- 至少 20 条合成中文/中英混合/长短句，导出模型与固定参考实现逐句 cosine ≥ 0.999；不达标先定位 tokenizer、pooling、截断和导出算子，不能以分类碰巧相同替代数值对齐。
- 批量与逐条编码一致；空输入、数量错误、维度错误、NaN/Inf、零向量和缺失文件有明确结果。字符哈希保持当前确定性输出。
- 本地模型推理不阻塞事件循环；加载复用、线程/队列有界、超时后的任务不污染结果。
- 假后端测试与真实模型一致性测试分开，普通测试零网络、无隐式下载。

## 边界

不把 Sentence Transformers 当作现有依赖直接安装到生产环境；构建参考环境单独锁版本。优先修复具体兼容错误，不扩大成全仓库依赖升级。模型文件放 ignored data，源与导出摘要进入可提交清单。
