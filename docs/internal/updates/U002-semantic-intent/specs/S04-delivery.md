# S04 运行接入与学习交付

归属：[U002 计划](../plan.md)。任务：05、09、10。

## 运行

提供一次性模型准备入口和固定清单校验，使用既有 Compose 启动方式。模型下载/导出在准备或构建阶段完成，运行镜像包含可离线使用的模型与 tokenizer，生产层不携带构建用 PyTorch 环境。重建容器不修改现有 Redis/Chroma 卷。

验证 Python 3.12、Windows 本地与 Linux 容器的加载路径和权限；检查生产依赖兼容性、构建来源与资产摘要。模型缺失/损坏可明确降级，准备命令失败必须返回失败，不能仅因 API 能以哈希启动就宣称模型部署成功。

## 真实验收

- 完整后端回归通过；前端现有测试和构建通过（无需重新设计界面）。
- 使用隔离验证项目/数据作用域完成查号、待确认、确认、查询、取消、患者切换、多轮承接、健康咨询和报告入口回归；原业务不因向量更新改变事实或越过确认。
- 真实本地 embedding + 真实 DeepSeek 执行一次固定候选报告，验证 `/chat`、直接编排、意图评测和隔离业务评测使用预期模型；报告列实际 semantic/hash/disabled 样本数。
- 在隔离实例注入模型缺失或损坏，验证 hash fallback、分数门槛、诊断以及重启恢复；固定急症期间普通 LLM 和 embedding 调用数均为零。
- 日志与报告记录模型/模板/校准/数据/源码指纹、机器、超时、失败和环境，旧报告不改写，候选不自动覆盖已接受基线。付费模型每份冻结输入只执行一次正式验证；有明确修复时才有界复测并保留旧失败。
