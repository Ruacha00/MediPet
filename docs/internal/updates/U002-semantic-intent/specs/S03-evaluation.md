# S03 独立语义评测与阈值校准

归属：[U002 计划](../plan.md)。任务：06、07、08。本 spec 的指标是预先约定的验收条件，不是当前测量结果。

## 数据与防泄漏

- 保留现有 `evaluation/cases/intents.json` 66 条及原多轮/边界集作为回归，新增 `evaluation/cases/semantic_intent/dev.json` 和 `holdout.json`。
- 对原意图集覆盖的每个类别至少开发集 6 条、留出集 10 条；OTHER、歧义、上下文省略和固定急症另设分组，不混入无上下文的业务向量主指标。06 实际盘点类别数并记录最终数量。
- 每条记录稳定 ID、消息、期望类别、表达家族、现象标签、标注理由、是否需上下文。holdout 中低字面重合子集至少 40 条，覆盖至少 8 个普通业务意图；06 在推理前冻结字面重合判定规则及标签，不以模型得分挑选容易样本。
- 按表达家族分割，检查与模板、learn 样本及其他 split 的标准化重复和近似表述；标注复核先于推理。留出集不用来增补模板、调阈值或改预期。
- “取消预约/不取消预约”不能仅凭语义相反标成两个不同意图。重点困难类别为查号源/查已约记录、准备预约/准备材料、科室介绍/症状分诊等；急症否定与实际动作由原边界测试单独负责。
- 当前消息向量不承担“明天呢”的上下文恢复；这类数据用于融合与多轮评测，不纳入单句向量应正确的分母。

## 对照与证据

固定同一模板、关键词、模型版本、预处理、机器和数据，比较 hash、semantic、disabled 三种模式。真实 embedding 单路先做排名；融合对照使用同一组冻结的 LLM 输出重放，避免两轮 LLM 随机性掩盖差异。假 LLM 固定输出只证明机制，不能称真实 DeepSeek 效果。正式融合门槛必须使用08采集的一批真实 DeepSeek 原始分类响应，记录模型参数、请求与输出指纹；不向分类模型提供期望标签。先完成开发集阈值冻结与真实向量验证，再按冻结清单每例调用一次聊天模型供三模式共同重放，不为不同向量模式重复调用。失败与重试单列，不用正确答案替补失败。

为归因保留两组比较：旧哈希与语义的原始模板排名（只换编码器）；采用相同新门槛/降级策略的三模式融合。另列相对提交 7a4e22a 的行为变化，不能把降级修正带来的提升全归因于 embedding。

报告必须包含：分支 Top-1、Macro-F1、Top-3、类别混淆、低字面重合子集；融合 Accuracy/Macro-F1、OTHER/澄清比例；故障时已接受样本的准确率与覆盖率；实际降级数、错误用例和原始分数。相似度不是概率，百分比同时给样本数。

性能报告区分模型加载、模板构建、首查询、暖查询、缓存命中；暖查询至少 100 次，记录 P50/P95、峰值 RSS、CPU/线程数、并发度和环境。计时不混入 DeepSeek 延迟。

## 校准与预先门槛

1. 仅用开发集为 semantic/hash 分别选择最小分数和跨类别分差，每后端最多 25 组预先列出的组合。关键词强匹配门槛也在开发阶段冻结；不调正常 `.7/.2/.1` 与最终 `.5`。
2. 冻结配置和模板后运行一次留出集。语义分支整体 Macro-F1 不低于哈希，低字面重合子集 Top-1 至少提高 **5 个百分点**；这是启用语义默认模式的效果门槛，不保证事先能达到。
3. 相同 LLM 输出重放下，原 66 条回归不得新增错误；留出集融合 Macro-F1 不低于 hash 对照。若两者都为满分，报告持平，不能声称融合准确率提升。
4. LLM 故障、无需上下文的可判定子集：接受结果准确率至少 **90%**，覆盖率至少 **50%**，同时列出拒绝与误接收。不能全部返回 OTHER 来“通过”准确率门槛。
5. 急症、否定边界、身份、预约确认等确定性用例全部通过。暖向量查询 P95 初始预算为 **500 ms**、等待上限候选 **2000 ms**；若本机不满足，先报告实测并修订配置/实现，不悄悄放宽预算。

未满足门槛时结果仍为 candidate，不将真实语义接入标为验收完成。不通过反复查看留出失败并调参来获取通过；必要的缺陷修复保留前后记录，受污染留出集需更换独立样本后再评价泛化。
