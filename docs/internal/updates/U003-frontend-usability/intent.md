# U003 前端可用性与展示精简

日期：2026-09-17。状态：用户已授权实施，源码与验证进行中。

用户要求：提高前端可用性，减少没有对应功能的花哨展示，先制定计划。用户已确认：**就诊操作优先，管理与调试放到次级入口**。

## 目标

让使用者能明确知道正在为谁办理、当前事项是什么、接下来可以做什么、操作是否真正完成。保留现有业务能力与学习价值，把工程细节放到需要时可查看的位置。

## 范围

- 基于现有Vue前端、组件及API增量改进，优化页面层级、消息阅读、事项管理、业务卡片、输入上传、移动端与键盘操作。
- 无实际动作的控件删除或改为普通信息；有功能但面向管理的入口下移；必要的就诊上下文、来源、演示标识和状态反馈保留。
- 不为装饰控件补造新功能，不增加账户中心、真实支付、地图导航、医院接入或新的模型能力。管理入口下移是信息架构调整，不是新增权限系统。
- 本轮不更换整体品牌、不新增主题切换器；沿用现有色系，减少渐变、阴影和大面积宣传占位，提高文字与控件辨识度。
- U002质量门槛未通过、09待验收的状态继续保留。前端优化不证明模型质量提升，也不自动接受候选基线。
