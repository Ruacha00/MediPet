# U001-09 PDF与图片提取

范围与文件所有权见[计划](../plan.md)，输入/输出见[契约](../contracts.md)。

验收：本地提取与OCR、格式/大小/页数/时间边界通过，合成三类文件真实验证。

## 完成记录

2026-09-16，spec_api_ui 完成 `health/report_upload.py`、固定 Python 依赖及镜像 OCR 语言包。文字 PDF 经 pypdf 提取；扫描页由 PDFium 渲染；图片和扫描页用本地 Tesseract 中英文 OCR。每次独立工作进程，原文件不持久保存；结果交给 U001-08 预处理。

限制为 10 MiB / 10 页 / 1600 万像素 / 100000 字符；单页 OCR 10 秒、总处理 120 秒、最多两个工作进程。明确拒绝损坏、加密、扩展名或 MIME 不符、无文字及超限输入；OCR 低置信度数值全部退回待核对。

与 U001-08/10 共用的测试最初 36 项通过，补充回归后 **39 项全部通过**。其中真实本地 Tesseract 验证文字 PDF、扫描 PDF、英文 PNG、中文 PNG，以及真实子进程文字提取；格式、页数、像素、OCR 超时/失败/低置信度有确定性边界测试。后续修复混合页文字页眉导致跳过扫描正文的问题：含图页整页 OCR，同时保留原文字层、仅去除完全相同的重复行；真实混合 PDF 及低置信度回归通过。详见[报告验证记录](../evidence/reports.md)。不把本地 OCR 证据称为容器验收；容器及页面由 U001-13 记录。
