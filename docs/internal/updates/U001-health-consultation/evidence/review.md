# U001 独立源码审查

2026-09-16，基准 c712e87，对照 U001 意图/契约与当前工作树；关注医疗边界、路由、急症、报告隔离和上传。只读源码并执行内存合成输入探针；没有调用模型、访问真实患者资料、启动服务或重建索引。没有重复审核临床来源。以下为审查时实际复现的问题，不把规则局限泛化成通用识别要求。

## 已复现问题

### 1. P1：此前非急症的否定会覆盖“并且现在/且现在”的肯定急症

- 入口：[core/emergency.py](../../../../../core/emergency.py) 第 31、102–109 行（审查快照）：只按标点/既有转折拆分，`_NEGATED.search(prefix)` 搜索目标前面的整个剩余分句。
- 内存调用 `detect_emergency("我没有发热并且现在呼吸困难")` 与 `detect_emergency("我没有胸痛且现在呼吸困难")` 均返回 `False`；加入“，但现在”的对照返回 `True`。已支持的呼吸困难信号被无关症状的否定遮住。
- 影响：API chat、编排 run 和评测 `_turn` 共用此函数，错误的 False 会使明确当前阳性继续普通分类/模型路径，违背急症前置约定。
- 最小修正：仅将明确“并且现在/且现在”视为新的当前分句；保留“没有呼吸困难和胸痛”与“如果……并且现在……”的否定/假设范围，增加正反例和零模型接口回归。root 已授权由本审查 agent 单独修复，完成结果另记下文。

### 2. P2：症状持续“3个月”被当作儿童月龄

- 入口：[health/triage.py](../../../../../health/triage.py) 第 37–44 行：没有“岁”时，任意 `数字+个月` 都将年龄段设为 child。
- 实际 `triage_symptoms("我咳嗽3个月了，该看哪个科？")` 返回 `dep_pediatrics`，`missing_information=[]`；中文“两个月”对照则询问年龄；明确“我36岁，咳嗽3个月”返回内科。
- 影响：没有年龄依据却生成儿童科室卡片，不符合年龄资料不足先澄清的约定。
- 最小修正：只将明确年龄/月龄表述解释为年龄，持续时间保持为持续时间；补“持续3个月但年龄未知”和明确儿童月龄的相邻反例。

### 3. P1：药名子串校验允许丢弃用户明确的未知剂型

- 入口：[agents/tools.py](../../../../../agents/tools.py) 第 218–230 行，以及 [health/medications.py](../../../../../health/medications.py) 第 19–21 行：工具只检查参数是否为用户文字的子串，目录允许“布洛芬”通用名别名。
- 实际用户原话“我手上是布洛芬缓释胶囊，想查看说明书。”，工具参数 `drug_name="布洛芬"` 返回 success，剂型为 `200 mg 普通包衣口服片`、来源数 1；同一句使用完整 `drug_name="布洛芬缓释胶囊"` 才返回“未核实”、来源数 0。
- 影响：即使用户明确提供未收录剂型，模型截短参数仍能拿到另一剂型的用量标签。提示词要求不擅改剂型，但服务端未守住这项契约。
- 最小修正：依据用户明确的完整药名/剂型约束允许查询的参数；未知缓释、复方、儿童液体等不能被通用名子串变成已收录产品。保留仅询问通用名时展示指定标签范围的既有行为，补工具入口反例。

### 4. P2：扫描 PDF 的文字页眉会使整页扫描内容跳过 OCR

- 入口：[health/report_upload.py](../../../../../health/report_upload.py) 第 105–107 行：仅在 `extract_text()` 完全为空时才 OCR。
- 在内存合成单页 PDF：主体为含 `WBC 6.2 mg/L 4.0-10.0` 的扫描图片，叠加文字页眉 `Scanned report`；以记录调用次数的 OCR 替身传入 `extract_report`。实际结果为 `extracted_text="Scanned report"`、0 observations、0 次 OCR。
- 影响：带文字页眉或水印的扫描报告可上传成功，但主体检验数据未被提取；通用“部分内容待核对”提示没有说明整张扫描主体未处理。
- 最小修正：对含扫描主体的页面有明确 OCR/混合内容处理策略，至少不能仅凭非空页眉判定已获得报告文字；加入此混合页反例，保留纯文字 PDF 不需 OCR 的路径及像素/时间限制。

## 已核对但未发现新问题的路径

- API 上传先加载绑定患者/事项；历史 append 再核验归档及身份，既有测试含 OCR 期间归档反例。`read_current_report` 重新校验同患者同事项，未发现跨事项回退。
- 上传仅使用 bytes/内存文档，不将文件名作为文件系统目标；扩展名/MIME/图片实际格式、大小、页数、像素、加密 PDF、单页 OCR/整体超时和工作进程并发有显式限制。此结论不等同于恶意 PDF 模糊测试或生产级服务压测。
- 前端以绑定事项快照和 epoch 接收上传结果；报告原文使用 Vue 文本插值，未发现将报告内容作为 HTML 执行。
- 六角色白名单保持隔离；报告由 TriageAgent 处理，药品工具无预约执行权限。新三类意图映射、急症前置与当前报告读取入口均已接入；未以未运行的模型路由结果宣称分类准确率。
