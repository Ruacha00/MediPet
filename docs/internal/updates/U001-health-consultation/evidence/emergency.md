## 实现与影响

- [core/emergency.py](../../../../../core/emergency.py)：保留 `detect_emergency(message) -> bool`、`is_emergency_reference(message) -> bool` 和固定响应常量；症状词包括胸痛/有限口语别名、呼吸困难、意识丧失/昏迷。匹配命中后仍由原 API/编排急症入口触发 CRITICAL。
- NFKC 统一全角数字和 ℃。温度支持阿拉伯数字小数、度/℃/°C/摄氏度、两端有单位或末端有单位的区间。区间两端均须超过阈值；39.5、≥39.5、39.5～40、40以下不被当作已确认超过阈值。显式“超过39.5”可命中。人体摄氏数字范围有界为 30～45；不做华氏换算、无单位数值或中文数字解析。
- 否定与存在性提问在当前分句排除；过去、假设和知识询问保留逗号后的语境，句号/问号等结束该语境。过去描述可被后续明确当前描述更新。“没有胸痛但呼吸困难”可命中后半句；“昨天胸痛，现在没有了”不触发。
- 编辑前 GitNexus 明确指定工作树 `D:/Projects/Agent Learn/Project/MediPet-Rebuild`，索引提交 c712e87 与实施基准一致；分支标签仍为旧名称。`detect_emergency` 上游为 CRITICAL：20 个节点、11 个直接调用；`is_emergency_reference` 为 HIGH：5 个节点、2 个直接调用。结果 exact，未报告 partial/truncated；已在编辑前告知 root。
- 已读直接调用源码：API `chat`、编排 `run`/`EscalationAgent.handle`、意图识别/模式票/紧急度、评测 `_turn`。统一函数继续保证入口与评测一致。模式识别新增信号的直接急症票由 root 在其所属文件接入。

## 实际验证

执行：

```text
.venv/Scripts/python.exe -m pytest tests/test_health_emergency.py tests/test_intent_recognizer.py tests/test_agent_orchestrator.py tests/test_chat_api.py -k emergency -q --junitxml=.scratch/U001-emergency.xml
```

结果：**152 passed，177 deselected，14.15s**。本次新文件与原急症回归一起执行；原分类/编排/API 全量回归仍由 U001-12 统一验收。JUnit 位于忽略的 `.scratch/`；可重复入口是 [test_health_emergency.py](../../../../../tests/test_health_emergency.py)。`git diff --check` 通过。

- 正反例覆盖四类信号、摄氏温度边界/区间、非人体温度、否定/假设/历史/知识询问、不同分句中实际阳性，以及“喘不过气”的词语重叠。
- 新增四个 API 阳性用例实际装配 API、编排和记忆函数，模型、Redis 与 Chroma 为替身：分别以胸痛、呼吸困难、昏迷、39.6℃证明 CRITICAL → EscalationAgent、零普通模型/召回/画像调用、无工具执行、`compress=False`、儿童患者绑定及完整历史/窗口各两条。
- 四个 API 反例进入普通分类流程。既有急症回归继续覆盖预分类不能绕过急症、预约方案与库存不被修改、否定句不抹去原事务意图。
- 首轮反例发现“喘不过气”中的“不过”误分句，后续新增非人体例发现“水烧到40度”与“烧到”重叠；分别修正分句与温度语境优先级，最终以上命令通过。没有为通过测试调用真实模型或修改服务契约。

## 独立审查后的定向修补

[审查记录](review.md) 复现“我没有发热并且现在呼吸困难”被无关否定覆盖。本次仅将“并且现在/且现在”处理为保留当前时间词的弱分句边界；不拆“没有呼吸困难和胸痛”，也不清除假设/知识语境。新增 5 个阳性、5 个反例与 2 个 API 零普通模型用例。

实际命令 `.venv/Scripts/python.exe -m pytest tests/test_health_emergency.py tests/test_intent_recognizer.py -k emergency -q --junitxml=.scratch/U001-emergency-review.xml`：**148 passed，58 deselected，11.14s**。此命令范围不同于上述 152 项回归，不将两个计数相加为覆盖数或质量率。

## 局限

这是有界词表、分句与温度规则，不是通用医学语言理解、分诊模型或临床安全认证。复杂省略、引用、跨句假设、未列口语以及混合测量可能漏报或误报；未命中绝不表示没有急症、可以等待或阈值以下安全。规则只看当前消息，不从历史摘要推断正在发生的急症。不修改预约事务、患者权限或确认接口；最终全量回归和真实场景验收仍由后续任务完成。
