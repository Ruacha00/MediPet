# U002 独立中文意图数据

本目录用于开发集校准与留出评测，不是训练语料或新的 Few-shot 模板。全部文字为合成输入，由本次数据编写任务直接撰写；未调用 embedding、DeepSeek 或其他模型对样本推理、评分、筛选。现有 66 条回归、69 条模板和已有多轮/边界数据未修改。

## 文件与分母

| 文件 | 用途 |
| --- | --- |
| `dev.json` | 开发集；可用于事先限定的门槛搜索 |
| `holdout.json` | 留出集；参数、模板与规则冻结后正式评价，禁止输入 learn 或据此校准 |
| `references.json` | 基准提交的69条模板与66条回归快照；只用于字面重合与重复检查，不能作为新增模板输入 |
| `authoring-families.json` | 样本编写时的家族分组，每家族两条；前三家族进入dev，后五家族进入holdout |
| `overlap-review.json` | 高字面近似候选及人工处理理由 |
| `manifest.json` | 规则、数量、文件指纹与独立审阅状态 |

基础数据覆盖原回归的18类，每类dev6条、holdout10条。每个split另有4条需上下文、2条歧义控制输入。dev共114条，holdout共186条。`single_turn` 主指标分别96/160条，覆盖16类；急症、OTHER、上下文省略及歧义各自报告，不能混入主分母。主指标中的问候和反馈可用于分类指标，但不进入“普通业务低字面重合”子集。独立审阅状态以manifest为准；未审阅不能以结构测试通过代替标注验收。

## 单条schema

每条含 `id`、`message`、`expected_intent`、`expression_family`、`phenomena`、`label_reason`、`requires_context`、`history`、`evaluation_group`、`vector_primary`、`llm_failure_eligible`、`business_intent`、`lexical_overlap`。分类请求只能读取message及明确允许的history，不能把期望类别、理由、家族或分组送进分类模型。

- `single_turn`：单句已明确要做什么，可纳入向量主指标及LLM故障时的可判定集合。
- `emergency`：当前肯定急症，验证固定中断；不以这组成绩声称向量懂急救。数字高热沿用产品阈值，不是临床诊断数据。
- `other`：本数据约定的无诉求或就诊/健康领域外内容；单独统计拒绝行为，不从主指标中隐去失败。
- `context_required`：只看当前一句不足以还原具体诉求，history提供固定合成上下文；由LLM承担承接，不要求当前消息向量恢复历史。
- `ambiguous`：对象缺失、仅否定或矛盾未决，期望OTHER并澄清；不进入可判定故障覆盖率的分母。

`requires_context` 指**分类**是否需要历史，不是执行业务是否需要状态。例如“为当前列表第二项准备预约”已足以识别创建意图，但仍需要服务端事项、真实列表和按钮确认；数据标签不赋予执行权限。“读取当前事项报告”可判为报告意图，实际报告内容仍只能由该事项工具取得。

## 标注边界

1. 医院整体公开资料、科室范围、医生介绍/排班，与可预约库存分开；已占用的预约记录不是查剩余号。
2. 预约创建、读取、取消按明确诉求标注，全部只是分类输入；“准备材料”不等于准备预约。
3. 就诊手续次序与院内空间路线分开；个人症状寻求科别与查科室简介分开。
4. 未收录的药品或剂型仍可判为药品信息意图；类别正确不证明标签已收录，更不证明药物安全。合成报告只要求整理原文，不提供疾病判断。
5. 否定不是独立意图标签。“不想取消”不能直接推成创建；没有其他明确请求时放入歧义组，不将其当作取消意图的普通负例来制造向量提升。
6. 表达家族描述同一话语框架下的成对措辞，家族不跨split。字符检查不能证明语义独立；审阅者需检查是否只是换人物、日期、药名或同义词后把同一家族拆到两边。

## 推理前固定的字面规则

规则ID为 `nfkc_alnum_bigram_jaccard_v1`。文本先Unicode NFKC、casefold，再仅保留Unicode字母与数字（Python `str.isalnum`）；以相邻两个字符的集合计算Jaccard，长度不足2时使用整个规范化字符串。对references全部135条计算最大值。

`low_literal_overlap = vector_primary AND business_intent AND max_reference_jaccard <= 0.20`。此标签由固定字符算法产生，不能依据任何向量排名或LLM答案改动。holdout低重合必须至少40条且覆盖8个普通业务意图；这不是人工挑出的最容易样本，也不等于模型间完全没有语义重叠。数值以manifest为准。

高近似复核条件为Jaccard≥0.60或规范化字符串的 `difflib.SequenceMatcher(autojunk=False).ratio()`≥0.84；完全相同一律失败。检查新数据对references，以及新数据不同表达家族之间；同家族变体保留在同一split。被标记项必须逐项说明，不能只调阈值让检查变绿。受控否定例外只能留在歧义/边界组，不能算主指标或低重合样本。

## 防泄漏与后续使用

使用新识别器和基准模板快照，运行期learn样本必须为空，不复用线上进程的可变状态。各模式使用相同模板和冻结LLM响应；模型参数、模板、校准、数据与请求/响应指纹由07/08记录。假LLM只能验证机制，不能替代真实融合门槛。

标签及家族独立审阅在推理之前完成。holdout正式运行一次；看过失败后修实现须保留失败记录并声明该集合已被查看。若据此改变模板、门槛、标注或选择子集，旧holdout不能继续证明泛化，应准备新的独立样本。存储为JSON并不构成保密隔离，需靠任务所有权、运行清单和指纹检查落实使用边界。

数据检查入口：`python -m pytest tests/test_semantic_intent_dataset.py -q`。它只检查内容结构、分组、泄漏风险和冻结记录，不运行模型，也不能证明分类效果。
