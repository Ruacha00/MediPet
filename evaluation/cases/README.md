# MediPet 评测输入

- `intents.json`：54 条独立措辞，12 个主要意图各 4 条，另含问候、反馈、模糊输入。标签使用当前 IntentCategory，expected_agent 用四角色值。
- `dialogs.json`：12 组多轮场景，固定参与者、患者及前置状态，记录可核对的业务断言。
- `boundaries.json`：12 组边界，包括未确认、重复操作、旧方案、身份冲突、无结果、检索故障、否定与一般急症咨询、模型不可用、到期和并发。

数据集固定业务时钟为 2026-09-16 10:00 Asia/Shanghai；使用明和虚构医院的预置患者、科室、医生与七天号源。正式运行应记录实际采用的时钟、模型、参数、数据摘要和代码版本。不是每条意图输入都能独立执行业务，单轮分类评测与多轮事务场景分开。

`turns` 是用户聊天内容。`setup` 是用例前置资料，`between_turns` 的数字键为下一轮的零基索引，`after_turns` 是聊天后的明确界面动作。患者切换、归档/恢复和确认属于测试驱动的用户操作，不能把这些动作伪装成模型工具权限。未填写操作的用例不得擅自执行确认。

`assertions` 是预期业务事实说明，由对应确定性测试和场景驱动核对，不能用 Judge 的语言评分替代。号源和预约编号必须从当次结果取得，文档不硬编码可执行 ID。检索故障、模型故障和竞争边界需显式故障注入，不以正常问答代替。

当前只完成数据与标签校验。模型准确率、场景通过率及人工接受基线由后续评测记录，不能根据这些预期值生成测量结果。
