# MediPet 简历包装指南

按原版项目经历的组织方式，先交代业务场景，再说明关键技术、个人工作和量化结果。以下提供通用版、后端版与精简版，最新交付与检索指标见[修复对照报告](../evaluation/reports/delivery-recall-20260918/notes.md)，意图与并发事务沿用[扩测证据](../evaluation/reports/business-expanded-20260918/notes.md)及其关联报告。

## 项目一句话描述

> MediPet 是面向医院、诊所及健康服务平台就诊服务场景的多 Agent 编排系统，支持就诊咨询、科室分流、号源查询、预约办理、用药信息查询与报告预处理，结合领域知识库、分层记忆、动态 Skills 和运行监控，实现可解释、可观测、可评测的服务链路。

### 端到端 Agent 怎么评测？

**回答思路**

评测保留原有两类模型检查，并补充业务状态断言与检索证据条件下的回答专项：

1. 意图识别评测：用标注用例计算 Accuracy 和 Macro-F1。
2. 端到端回复评测：真实调用 `Orchestrator.run()` 生成回复，再用 LLM-as-Judge 从四个维度打分。

新增回答专项对同一问题使用新旧检索证据生成回答，从正确性、证据支持、需求覆盖、无依据断言和资料不足处理五维评分。30题双组综合通过16/30→28/30；这与下方端到端四维Judge分别计分，不能把93.33%写成线上准确率。

四个维度是：

- `relevance`：是否回答用户问题。
- `accuracy`：信息是否准确。
- `completeness`：是否完整解决需求。
- `helpfulness`：用户能否据此行动。

业务断言独立检查真实工具、卡片、库存和患者范围；Judge不能证明预约已执行。Judge失败不进入有效均值。评测器与人工已接受基线比较，相对下降超过5%才标记regression，并生成建议；不是自动与上一轮候选比较。

U001 历史完整模型候选66/66意图，30/30质量、26/27业务，共57/58；路线提示修复后原样两轮3/3，未重跑完整58项。报告仍为`candidate`。后端684 passed/21 skipped与前端35项是另一层验证，最后提示修复后有119项定向检查。无需把全部数字堆进简历，细节见[验收](../docs/internal/updates/U001-health-consultation/evidence/acceptance.md)。

U002 可以讲清本地语义编码、整路降级、同空间缓存和受控对照的实现。若被追问效果，应说明低重合向量单路改善、三模式融合持平，LLM 故障接受准确率未达预定门槛；不能写成整体助手准确率提升或全部验收完成。可直接使用的数字与口头表述集中在[指标模板](带数据指标的加强版简历模板.md)。

修复前首轮业务专项在`bf4f353`上测得66/66固定意图回归、37/39业务状态组与52/54质量轮次；原有27组业务检查全通过，但新增表达暴露2条复合协同缺口。路线任务另有过度澄清造成的质量低分。报告全部保留为候选；可以用它解释为什么“回答有文字”“卡片已交付”“预约已落库”要分开检查，而不是宣称系统整体准确率达到某个百分比。


最新修复后，固定80个业务任务全部完成，145轮回复质量通过；其中复合首轮双卡片由11/20提升至20/20。检索配对Recall@3为51.25%→97.5%；回答专项为16/30→28/30，新版保留1条Judge引用无效和1条跨文档信息缺失。旧失败与新结果分批保存，详见[专项报告](../evaluation/reports/delivery-recall-20260918/notes.md)。

#### 口头表达：30秒与一个深入案例

“项目围绕患者事项做就诊协作：先查号和材料，选择后只生成方案，按钮确认才执行Redis事务。我重点讲[自己负责模块]，因为这里要把模型文字、实际业务状态和可恢复历史分开。健康扩展只提供有限分诊、指定标签和本地报告整理。”

深入追问可选一个本人实际参与的例子：

- 复合交付与知识召回：先用任务状态检查发现漏材料卡片，再补只读工具约束；以混合召回和正文重排修复知识缺失，分别核对任务完成、文档召回和回答效果，不能用一种指标代替另一种。
- 路线续问：首轮有普通路线，第二轮要无障碍时只复述而未调用工具；业务断言失败，修复Guidance提示后原输入两轮3/3，完整报告不覆盖。
- 混合PDF：页眉有文字不代表正文已提取；对含图页补OCR，保留文字层并标注待核对，使用合成文件回归。
- 确认重试：业务成功、历史失败时保留原回执，重试补历史和窗口失效，不再次扣库存。

这些是项目记录，不自动成为个人经历。证据见[审查](../docs/internal/updates/U001-health-consultation/evidence/review.md)与[路线复测](../evaluation/reports/live-20260916-u001-route-fix/notes.md)。
