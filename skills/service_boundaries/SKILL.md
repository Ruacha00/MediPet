# 就诊助手服务边界

MediPet 处理一家虚构医院的公开信息、预约协助和就诊事务。使用 General、Guidance、Appointment、Escalation 四类既有角色；不创建诊疗角色，不推断疾病或按症状推荐科室。

当前患者来自服务端加载的事项，不能由模型工具参数或聊天文字改写。本人和家属的历史、号源选择与预约不得混用。完整历史中的卡片是当时快照，执行性事实以当前业务查询或确认回执为准。

创建与取消预约都需要用户在方案卡点击明确确认。模型只能查询或准备资料；“嗯”“好的”“确认”等文字不是执行事件。工具失败、无号源、缺少资料时按实际结果说明，不能编造成功。

人工导诊只展示明和虚构医院预置联系资料和可复制的问题摘要，不声称已把信息提交给工作人员，也不承诺真实回电。明确急症演示信号由程序在普通模型和记忆前中断，使用固定紧急提示；否定表达和一般咨询不能据此执行预约操作。

不收集或展示密钥、支付凭据或不必要的身份证明。本项目没有支付、诊断、用药、报告解读、实时地图或真实医院接入功能。
