# 03: 扩展目录查询与预约取消能力

Type: implementation
Status: resolved
Blocked by: 01, 02

**What to build:** 将医院目录查询拆成可独立发现的 Skill，并为当前患者预约增加需要权威确认的取消 Tool 与独立 Skill。

- [x] 外置医院 Skills 在治理元数据中显式声明 Tool 绑定。
- [x] 开发引导发现、发布并激活多个外置 Skills。
- [x] 取消预约使用患者作用域、权威确认、重校验和幂等提交。
- [x] 取消后的预约保留取消状态，并释放对应号源。
- [x] Tool 契约变化使用新版本，新增行为有自动化测试覆盖。

## Answer

开发环境现包含独立的医院目录查询、预约挂号和预约取消 Skills。取消预约由新增的受信任写 Tool 执行，首次调用只产生确认提案；提交时重新核验预约状态与患者作用域，并以幂等收据记录结果。取消后的号源重新进入可预约集合。
