# 02: 打通号源选择、预约确认与历史恢复

Type: implementation
Status: resolved
Blocked by: 01

**What to build:** 将医院号源和预约提案作为结构化聊天数据持久化，支持准确选择号源、显示权威确认资料、提交决定并恢复最终状态。

- [x] 号源查询生成可选择的结构化卡片，点击选择向模型提供准确 `slot_id`。
- [x] 预约确认卡展示患者名称、服务医院、科室、医生、时间和费用，不展示内部患者 ID。
- [x] 确认和拒绝更新原卡片，成功展示收据。
- [x] 结构化数据和最终状态随聊天历史恢复。
- [x] 后端、前端与完整聊天场景测试覆盖。

## Answer

号源已作为结构化聊天数据呈现并支持精确选择；预约只生成服务器权威提案，确认或拒绝会原位更新卡片，成功时附带收据。卡片和最终状态均会持久化并随历史恢复。
