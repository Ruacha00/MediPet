# 01: 扩充基础门诊科室、医生与排班

**What to build:** 将默认虚构医院服务目录扩充到 24 个基础门诊科室，为每个科室配置医生和未来两周排班，并强化目录覆盖关系校验。

Type: implementation

Status: resolved

- [x] 默认目录包含规格列出的 24 个基础门诊科室。
- [x] 每个科室至少有一名医生，每名医生至少有一个排班模板。
- [x] 任一科室均有未来两周内的可预约号源。
- [x] 数据加载会拒绝无医生科室和无排班医生。
- [x] API 测试、Ruff 和 Pyright 通过。

## Comments

- 2026-08-30：按现有“医院服务目录”和普通预约挂号边界实施；急诊与医技科室不纳入可预约目录。

## Answer

默认虚构医院服务目录已扩充为 24 个基础门诊科室、24 名医生和 24 个相对排班模板，覆盖全科、主要内外科分支、妇产儿、五官口腔、皮肤、精神心理、康复、中医与感染科。现有 ID 和初始预约保持不变；加载器新增科室必须有医生、医生必须有排班的完整性校验。完整 API 测试 148 项通过（另有 8 项按环境跳过），Ruff 与 Pyright 均通过。
