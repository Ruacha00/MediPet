# 完善虚构医院服务目录

Type: spec
Status: resolved

虚构医院需要覆盖综合医院常见且可通过普通门诊号源预约的基础科室，供科室查询、医生筛选、号源搜索和聊天流程进行更完整的本地演示与测试。

## 范围

- 目录包含 24 个基础门诊科室：全科、普通内科及主要内科分支、普通外科及常见外科分支、妇产儿、皮肤、眼耳鼻喉口腔、精神心理、康复、中医和感染性疾病科。
- 每个科室至少配置一名医生，每名医生至少配置一个未来两周内的排班模板。
- 保留现有科室、医生、排班 ID 和初始预约，避免破坏已有演示链接及测试场景。
- 急诊科不使用普通预约挂号流程；检验、影像等医技科室不是当前目录中的独立门诊号源，均不纳入本次数据集。

## 完整性约束

- 科室、医生、排班及初始预约继续满足唯一 ID、引用完整性和合法号源时段约束。
- 不允许存在没有医生的科室，也不允许存在没有排班的医生。
- 数据仍由仓库内只读 JSON 提供，不写入 PostgreSQL。

## 验收

- 默认数据源可加载全部 24 个科室及其医生和排班。
- 任一科室都能查询到医生及未来两周内的可预约号源。
- 缺少医生或排班的目录在加载时明确失败。
- 相关 API 测试、Ruff 和 Pyright 通过。
