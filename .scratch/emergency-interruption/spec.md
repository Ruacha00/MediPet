# 明显急症中断与线下干预引导

Type: spec
Status: resolved

## 目标

当就诊参与者当前消息明确描述正在发生的急症信号时，MediPet 在调用模型前中断普通协助，持久化紧急转介卡并直接给出线下干预引导；不建立风险评分、人工审核、后台推送或恢复工作流。

## 验收

- 当前发生的明显急症信号产生一张 `data-handoff` 紧急卡片并绕过普通 Agent。
- 历史症状、明确否定以及清晰的科普或假设提问继续进入普通 Agent。
- 紧急转介使用类型化契约，急症识别规则与用户文案不由 Assistant 编排模块直接拥有。
- 通用人工导诊能力不因删除急症审核工作流而被移出架构。
- 后端测试、Ruff、Pyright 和前端消息卡片测试通过。

## Answer

已完成。Assistant 在模型调用前应用集中式确定性急症策略，当前明显信号会持久化并返回紧急转介卡；历史、明确否定、科普/假设和缺少当前语境的模糊症状继续普通 Agent。实现不包含风险评分、人工审核队列、后台推送或恢复流程，且保留通用人工导诊架构。后端 192 项测试通过、8 项跳过，Ruff、Pyright 与前端 17 项测试通过。
