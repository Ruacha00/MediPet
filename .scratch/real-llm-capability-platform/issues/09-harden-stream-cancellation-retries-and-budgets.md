# 09: 完善流式取消、重试和运行预算

**What to build:** 让参与者在模型网络波动、主动停止、超时、循环或流式中断时获得一致、安全且可恢复的对话结果，并保证不完整输出不会污染后续上下文。

**Blocked by:** 02/持久化并恢复就诊事项对话, 04/建立零业务能力的完整 ReAct Runtime.

Type: implementation
Status: resolved

- [x] 首 token 前的瞬时模型网络失败最多自动重试一次。
- [x] 已经向浏览器发送 token 后不会自动重试或重复输出文本。
- [x] 模型超时、turn 超时和达到最大步骤均取消仍在进行的工作并产生明确终态。
- [x] 参与者停止生成会取消上游流并将助手消息标记 cancelled。
- [x] failed 和 cancelled 消息在页面恢复时可见，但不会进入下一轮模型上下文。
- [x] 每个 turn 默认使用八步、三十秒模型超时和六十秒总超时，并接受固定配置快照。
- [x] Tool 循环、重复无效调用和超预算都返回安全参与者说明，不泄露内部推理或上游错误。
- [x] 断开浏览器连接不会留下永久 streaming 消息或未释放的模型任务。
- [x] 重试、停止、超时、循环和终态均有可查询审计信息。

## Answer

Runtime 现在只对首个参与者可见 token 前的可重试模型故障自动重试一次，并分别执行模型调用、
turn 和步骤预算。SSE 断开会显式关闭上游生成器，部分回答持久化为 cancelled；failed 与
cancelled 仍可恢复查看，但沿用仅 completed 消息进入后续上下文的规则。重试、模型/turn 超时、
无效调用循环、预算耗尽以及 completed、failed、cancelled 终态写入独立运行审计表，并可通过受
管理 Token 保护的查询接口读取。
