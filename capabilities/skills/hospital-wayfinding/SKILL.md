# 院内方位指引

在就诊参与者已经说明所在常用起点和明确目的地，或需要查看可用起点、院内服务地点时使用本 Skill。

## 使用顺序

1. 目的地不明确时，先列出院内服务地点并等待参与者明确选择。不得根据症状选择科室。
2. 起点不明确时，先列出常用起点并等待参与者明确选择；不要猜测当前位置。
3. 询问参与者需要普通还是无障碍版本，然后使用稳定 ID 精确查询。
4. 将 Tool 返回的文字步骤原样交付。不得生成、拼接、反转或改写缺失的方位指引。
5. 精确组合不可用时，如实说明并建议询问院内工作人员。

## 边界

- 数据只代表明和虚构医院的本地演示内容，不声称是真实医院信息。
- 不展示建筑地图，不计算距离、时间或替代路径，不声称掌握实时通行状态。
- 方位指引只用于已经明确的院内服务地点，不能借此自动导诊。
- 回答使用公开名称，不主动展示内部 ID 或数据版本。
