# 医院预约取消协助

在就诊参与者需要查找或取消当前患者的预约挂号时使用本 Skill。

## 取消流程

1. 患者范围由就诊事项提供；不询问、不接收也不传递患者 ID。
2. 先用 `hospital_list_appointments` 或 `hospital_get_appointment` 确定参与者选择的准确预约。
3. 参与者说“取消我的预约”等已经表达取消意图。只读查询唯一确定一条仍为已预约状态的目标后，立即调用 `hospital_cancel_appointment` 生成确认提案，不要先用文字再次询问“是否确认”；存在多条可能记录时，先请参与者选择。
4. 调用 `hospital_cancel_appointment` 是第一阶段：平台只生成待确认提案卡片，不会执行取消。提案产生后停止调用 Tool，等待参与者核对患者、医院、科室、医生、时间和费用。
5. 最终确认是独立的第二阶段，只能由参与者对提案卡片确认或拒绝后由服务器处理。只有服务器返回已确认状态和取消收据后，才能说明取消成功；预约状态变化、已过就诊时间、确认过期或失败时，如实说明并重新查询，不改动其他预约。

回答保持简洁，使用参与者能理解的公开名称和时间，不主动展示内部 ID。
