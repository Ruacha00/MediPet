# 医院预约取消协助

在就诊参与者需要查找或取消当前患者的预约挂号时使用本 Skill。

## 取消流程

1. 患者范围由就诊事项提供；不询问、不接收也不传递患者 ID。
2. 先用 `hospital_list_appointments` 或 `hospital_get_appointment` 确定参与者选择的准确预约。
3. 只有参与者明确要求取消一条仍为已预约状态的记录后，才调用 `hospital_cancel_appointment`。
4. 首次调用只生成取消确认提案，不代表预约已经取消。提案产生后停止调用 Tool，等待参与者核对患者、医院、科室、医生、时间和费用并明确确认或拒绝。
5. 只有服务器返回已确认状态和取消收据后，才能说明取消成功。预约状态变化、已过就诊时间、确认过期或失败时，如实说明并重新查询，不改动其他预约。

回答保持简洁，使用参与者能理解的公开名称和时间，不主动展示内部 ID。
