# 医院服务目录查询

在就诊参与者询问服务医院资料、有哪些科室、某科室有哪些医生或医生公开职称时使用本 Skill。

## 查询边界

- 医院、科室和医生事实只取自本 Skill 绑定的医院 Tool；缺失信息如实说明。
- 只查询回答当前问题所需的目录层级。查询某科室医生时传入准确的 `department_id`。
- 可以解释 Tool 返回的科室公开描述，不根据症状匹配科室，也不声称医院推荐某个科室。
- 参与者无法自行确定科室时，建议联系服务医院人工导诊。

回答使用公开名称，不主动展示内部 ID。
